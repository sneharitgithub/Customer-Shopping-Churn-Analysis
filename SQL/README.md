# SQL Analysis

This folder contains SQL scripts used to analyze customer shopping behavior and generate business insights.

## Files

### 01_Data_Validation.sql
- Data quality checks
- Record validation
- Dataset verification

### 02_Customer_Analysis.sql
- Customer spending analysis
- Revenue contribution
- Customer segmentation

### 03_Subscription_Analysis.sql
- Subscriber vs non-subscriber comparison
- Purchase frequency analysis
- Subscription impact on revenue

### 04_Churn_Analysis.sql
- Repeat purchase behavior
- Customer retention insights
- Loyalty analysis

### 05_Business_Insights.sql
- Product performance
- Revenue trends
- Seasonal analysis
- Payment and shipping preferences

## Database
- MySQL
- Dataset: Customer Shopping Trends
- Records: 3900
